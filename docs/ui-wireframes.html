S3 · Planning Phase (top-down map view)

TOP BAR: Wave 3/10 · ⏱ 0:47 · SCRIP 265 (shared) · civilians: Saloon 8 | Chapel 4 | Homestead 6
MAP: colony cavern, 3 hotspots (buildings), entry tunnels, TEAM SPAWN marker (center — heroes enter & respawn here). ACTIVE entry points for next wave pulse red (partial preview — types/counts hidden). Existing placeables shown; click one → SELL (50%) tooltip.
SHOP BAR (bottom):
Barricade 100 · Spike Trap 75 · Dynamite Trap 150 · Turret 250 · Med Station 200
click → ghost follows cursor → click valid zone to place (invalid zones tint red)
READY panel: 2/4 ready (denominator = connected players)
READY UP (starts combat early if all ready)
States: scrip too low → shop item greyed with cost in red; placement in invalid zone → rejected ghost shake; timer hits 0 → auto-transition to combat

S4 · Combat Phase (top-down action)

TOP BAR: Wave 3/10 · monsters left: 14 · civilians: 8|4|6 · SCRIP 265 (+ticks on kills)
WORLD: WASD move (W reserved for movement only) · hero faces mouse cursor · SPACE = basic attack toward cursor · Q = ability 1 · E = ability 2/ultimate (both locked until unlocked with skill points). Hotspots show civilian count over building. Barricades show HP bars when damaged.
SELF (bottom bar): HP · class icon · SPACE/Q/E slots with cooldown sweeps (locked slots show padlock) · XP bar + account level · skill-point badge when unspent
Level up → toast + badge; opening picker (hotkey L or click badge) shows choice cards: Unlock Q · Unlock E · Rank up unlocked ability (max rank 3). Non-blocking overlay, sim keeps running.
States: hero dead → grey overlay "Respawning in 7s", camera follows a living ally; civilians_killed → red flash + toast "Civilians lost at the Chapel!"; hotspot emptied → building marked dark/lost; monster spawn → entry point flare

S5 · Wave Complete (interstitial, ~3s, then back to S3)

Banner: "WAVE 3 CLEARED" · bounty earned this wave: +180 scrip · civilians remaining: 18/20

S6 · Victory

"THE COLONY STANDS" · civilians saved X/20 · kills per player table · scrip spent
PLAY AGAIN (same lobby) host-only; resets match state, party returns to S2 with same code & classes; profiles persist MAIN MENU

S7 · Defeat

"THE COLONY HAS FALLEN" · reached wave N · same stats table
RETRY (same lobby) host-only; same semantics as PLAY AGAIN MAIN MENU

Cross-cutting states

Player disconnects mid-match → their hero despawns; monsters retarget; match continues; toast shown. Host disconnects → match ends for all → S1 with error message (v1: no host migration).
Pause: none in multiplayer. ESC opens overlay menu (leave match, volume) without pausing sim.
